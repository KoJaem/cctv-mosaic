# CCTV 얼굴 모자이크

영상에서 얼굴을 자동으로 찾아 모자이크 처리합니다. 두 가지 방식이 있습니다.

- **전체 모자이크**: 감지된 얼굴을 모두 가립니다.
- **특정 인물 제외**: 지정한 한 사람만 남기고 나머지 얼굴을 모두 가립니다.

모든 처리는 이 컴퓨터 안에서만 이루어집니다. 영상과 얼굴 사진은 외부(클라우드, AI 서비스 등)로 전송되지 않으며, 인터넷 연결 없이도 동작합니다.

## 폴더 구조

```
cctv-mosaic/
├── mosaic.py                              실행 스크립트
├── test_mosaic.py                         동작 확인 테스트
├── face_detection_yunet_2023mar.onnx      얼굴 감지 모델
├── face_recognition_sface_2021dec.onnx    얼굴 인식 모델 (특정 인물 제외용)
├── target/   원본 영상을 넣는 곳
├── result/   결과 영상이 저장되는 곳 (자동 생성)
├── faces/    영상에서 뽑은 얼굴 사진 (얼굴 추출 시 자동 생성)
└── keep/     모자이크하지 않을 인물의 사진을 넣는 곳
```

## 실행

```bash
cd ~/Documents/cctv-mosaic
python3 mosaic.py
```

실행하면 작업을 먼저 고르고, 그다음 `target/`의 영상을 고릅니다.

```
작업 선택:
  1. 전체 얼굴 모자이크
  2. 특정 인물 제외하고 모자이크 (keep/ 사진 사용)
  3. 얼굴 추출 (keep/ 에 넣을 사진 고르기용)
작업 번호: 1
/Users/kojaemin/Documents/cctv-mosaic/target 영상 목록:
  1. 정문_1022.mp4
  2. 주차장_1022.mp4
영상 번호: 2
```

번호 대신 다른 값을 입력하면 다시 묻습니다. `Ctrl+C`를 누르면 취소됩니다.

## 방식 1. 전체 얼굴 모자이크

1. 원본 영상을 `target/`에 넣습니다.
2. `python3 mosaic.py`를 실행하고 작업 **1**, 영상 번호를 고릅니다.
3. 결과는 `result/<원본이름>_mosaic.mp4`로 저장됩니다.

```
완료: .../result/주차장_1022_mosaic.mp4
얼굴 감지된 프레임 812/1500. 자동 감지는 누락 가능 — 전달 전 전체 영상 직접 확인 필수.
```

물어보지 않고 바로 실행하려면 다음과 같이 합니다.

```bash
python3 mosaic.py --mode all
```

## 방식 2. 특정 인물 제외하고 모자이크

한 사람만 얼굴을 남기고 나머지는 모두 가립니다. 과정은 **얼굴 추출 → 사진 고르기 → 실행 → 확인** 순서입니다.

### 2-1. 얼굴 추출

```bash
python3 mosaic.py          # 작업 3 선택 후 영상 선택
```

영상에서 1초에 한 번씩 얼굴을 잘라 `faces/<영상이름>/`에 저장합니다. 파일 이름은 영상 속 시간과 얼굴 번호입니다(예: `01m12s_0.jpg`는 1분 12초 장면의 0번 얼굴). 모자이크는 하지 않습니다.

얼굴이 하나도 저장되지 않았다면 얼굴이 너무 작거나 감지가 안 된 것입니다. `--scale 2.0` 또는 `--threshold 0.4`를 붙여 다시 실행해 보세요.

### 2-2. 남길 인물의 사진 고르기

```bash
open faces
```

Finder에서 사진을 보고, 모자이크하지 않을 인물의 사진 **3~10장**을 `keep/` 폴더로 **복사**합니다.

- 정면, 옆모습, 다른 시간대 등 다양하게 고를수록 인식이 잘 됩니다.
- 흐리거나 반쯤 가려진 사진은 빼세요.
- 다른 영상이나 사진(증명사진 등)도 쓸 수 있지만, 같은 CCTV에서 뽑은 사진이 인식률이 가장 좋습니다.
- ⚠️ **다른 사람 사진이 한 장이라도 섞이면 그 사람도 모자이크되지 않습니다.** 가장 주의할 부분입니다.

### 2-3. 실행

```bash
python3 mosaic.py          # 작업 2 선택 후 영상 선택
```

```
keep/ 사진 5장 — 이 인물은 모자이크 제외
...
완료: .../result/주차장_1022_mosaic_keep.mp4
얼굴 감지된 프레임 812/1500. 자동 감지는 누락 가능 — 전달 전 전체 영상 직접 확인 필수.
모자이크 제외 구간: 00:12~00:45, 01:03~01:10
이 구간에서 해당 인물만 노출되고 다른 사람은 가려졌는지 꼭 확인하세요.
```

결과는 `result/<원본이름>_mosaic_keep.mp4`로 저장되어, 전체 모자이크 결과와 이름이 겹치지 않습니다. `keep/`에 쓸 수 있는 사진이 없으면 실행하지 않고 안내만 출력합니다. 얼굴을 찾지 못한 사진은 경고를 출력하고 건너뜁니다.

### 2-4. 확인 (필수)

1. **"모자이크 제외 구간"을 먼저 확인합니다.** 해당 인물만 노출되고, 같은 화면의 다른 사람은 가려졌는지 봅니다.
2. **영상 전체를 확인합니다.** 자동 감지가 놓친 얼굴이 없는지 봅니다.

### 판단 기준

다른 사람을 해당 인물로 잘못 인식하면 제3자의 얼굴이 노출됩니다. 그래서 **애매하면 가리는** 쪽으로 설정되어 있습니다. 아래 조건을 **모두** 만족할 때만 모자이크하지 않습니다.

| 조건 | 기본값 | 옵션 |
|------|--------|------|
| `keep/` 사진과의 유사도 | 0.45 이상 | `--match` |
| 얼굴 크기 (가로·세로 중 짧은 쪽) | 40px 이상 | `--min-face` |
| 연속으로 해당 인물로 인식된 프레임 수 | 5프레임 이상 | `--min-frames` |
| 한 화면에서 해당 인물로 보는 얼굴 수 | 최대 1명 (가장 닮은 얼굴) | 없음 |

CCTV는 위에서 내려다보는 각도에 화질이 낮아서, 해당 인물도 일부 장면에서는 가려질 수 있습니다. 노출되는 쪽이 아니라 가려지는 쪽으로 틀리는 것이라 개인정보 측면에서는 안전합니다.

### 문제 해결

**해당 인물이 자꾸 가려질 때**
- 각도가 다른 사진을 `keep/`에 더 넣습니다.
- 얼굴이 작게 찍혔다면 `--scale 2.0`을 붙입니다.
- 그래도 안 되면 `--match`를 조금 낮춥니다(예: `0.40`). 낮출수록 다른 사람을 해당 인물로 잘못 볼 위험이 커지니, 결과를 더 꼼꼼히 확인하세요.

**다른 사람이 가려지지 않을 때**
- `keep/`에 다른 사람 사진이 섞였는지 먼저 확인합니다.
- 섞이지 않았다면 `--match`를 높입니다(예: `0.55`).

### 다른 영상·다른 인물을 처리할 때

`keep/`은 모든 영상에 공통으로 적용됩니다. 남길 인물이 바뀌면 `keep/`을 비우고 새로 고르세요.

### 작업 후 정리

`faces/`와 `keep/`의 얼굴 사진도 개인정보입니다. 작업이 끝나면 지우세요.

```bash
rm -rf faces keep
```

## 경로를 직접 지정해서 실행

`target/` 밖의 파일을 처리하거나 결과 위치를 지정하려면 경로를 직접 넣습니다.

```bash
python3 mosaic.py ~/"Desktop/CCTV 영상.mp4" --mode all              # 결과는 result/ 에
python3 mosaic.py ~/"Desktop/CCTV 영상.mp4" 결과.mp4 --mode keep    # 결과 위치 지정
```

경로에 공백이 있으면 따옴표로 감싸고, `~`는 따옴표 밖에 둡니다. 터미널 창에 파일을 끌어다 놓으면 경로가 자동으로 입력됩니다.

## 옵션 전체

| 옵션 | 기본값 | 설명 |
|------|--------|------|
| `--mode` | (물어봄) | `all` 전체 모자이크 / `keep` 특정 인물 제외 / `extract` 얼굴 추출 |
| `--threshold` | 0.6 | 얼굴 감지 기준. 낮출수록 더 많이 가립니다 (얼굴이 아닌 곳도 가려질 수 있음) |
| `--scale` | 1.0 | 감지용 확대 배율. 얼굴이 작게 찍혔으면 `2.0` (처리 시간 증가) |
| `--pad` | 0.4 | 얼굴 박스를 넓히는 비율 (머리·귀까지 가림) |
| `--hold` | 15 | 감지된 위치를 앞뒤 몇 프레임까지 계속 가릴지 (감지가 순간 끊겨도 노출 방지) |
| `--blocks` | 8 | 모자이크 칸 수. 작을수록 거칠게 |
| `--match` | 0.45 | (keep) 해당 인물로 판단할 유사도. 높일수록 엄격 |
| `--min-face` | 40 | (keep, extract) 이보다 작은 얼굴(px)은 인식하지 않고 무조건 가림 / 추출하지 않음 |
| `--min-frames` | 5 | (keep) 연속 몇 프레임 이상 인식돼야 모자이크에서 제외할지 |

예시:

```bash
python3 mosaic.py --threshold 0.4 --scale 2.0            # 얼굴이 빠진 장면이 있을 때
python3 mosaic.py --mode keep --match 0.55 --min-frames 10   # 더 엄격하게 인물 제외
```

## 결과물 특징

- 오디오는 제거됩니다 (목소리도 개인정보).
- 메타데이터(촬영 정보 등)는 제거됩니다.
- 영상에 직접 박혀 있는 날짜·시간 표시는 그대로 남습니다.

## ⚠️ 전달 전 반드시 확인

자동 감지·인식은 완벽하지 않습니다. **결과 영상 전체를 직접 재생해서 확인한 뒤 전달하세요.**

- 뒷모습·옆모습, 저화질, 어두운 장면, 멀리 작게 찍힌 사람은 놓칠 수 있습니다.
- 번호판, 이름표, 화면 속 문서 등 얼굴이 아닌 식별 정보는 가리지 않습니다.
- 특정 인물 제외 모드에서는 "모자이크 제외 구간"에 다른 사람이 노출되지 않았는지 반드시 확인하세요.

## 설치 (가상환경 `.venv`)

이 Mac에는 필요한 패키지와 모델이 이미 준비돼 있어 위 실행 방법대로 바로 쓸 수 있습니다. 다른 컴퓨터에서 쓰거나, 시스템 Python을 건드리지 않고 이 폴더 전용 환경을 만들고 싶을 때 아래처럼 가상환경을 사용합니다.

### 처음 한 번 (인터넷 필요)

```bash
cd ~/Documents/cctv-mosaic
python3 -m venv .venv              # 가상환경 생성
source .venv/bin/activate          # 가상환경 켜기
pip install opencv-python          # numpy도 함께 설치됨
brew install ffmpeg                # 선택. 없어도 동작하지만 결과 파일이 일부 플레이어에서 재생 안 될 수 있음
```

### 사용할 때마다

```bash
cd ~/Documents/cctv-mosaic
source .venv/bin/activate          # 프롬프트 앞에 (.venv) 표시되면 켜진 것
python mosaic.py
deactivate                         # 다 쓰면 끄기
```

켜고 끄기 없이 한 줄로 실행할 수도 있습니다.

```bash
.venv/bin/python mosaic.py
```

Windows에서는 `source .venv/bin/activate` 대신 `.venv\Scripts\activate`를 사용합니다.

### 참고

- 실행 중 `[ WARN:0@...] ... setPreferableTarget ...` 줄이 보일 수 있습니다. OpenCV 5.x의 안내 메시지이며 결과에는 영향 없습니다.
- `.venv` 폴더는 다른 컴퓨터로 복사해도 동작하지 않습니다. 새 컴퓨터에서는 `.venv`를 빼고 복사한 뒤 위 "처음 한 번" 과정을 다시 하세요.
- `.venv`가 꼬였으면 `rm -rf .venv` 후 다시 만들면 됩니다.

## 다른 컴퓨터로 옮기기

`.venv`, `target/`, `result/`, `faces/`, `keep/`을 제외하고 폴더를 복사합니다. `mosaic.py`와 두 `.onnx` 모델 파일은 반드시 같은 폴더에 있어야 합니다. 모델 파일이 없으면 처음 실행할 때 인터넷에서 다시 받으려고 시도합니다(감지 모델 약 230KB, 인식 모델 약 37MB).

## 동작 확인 테스트

```bash
python3 test_mosaic.py   # 마지막 줄에 "OK" 출력되면 정상
```

테스트는 합성 영상으로 처리 과정과 판단 규칙을 확인합니다. 실제 얼굴을 얼마나 잘 감지·인식하는지는 확인하지 않으므로, 실제 영상의 결과는 직접 확인해야 합니다.
